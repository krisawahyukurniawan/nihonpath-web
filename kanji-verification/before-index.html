Can I download NihonPath yet?

Not yet. NihonPath is in early development, and there’s no public app release linked from the repository. This page introduces the planned experience. Follow the GitHub project for development updates.

Is it a good fit for complete beginners?

That’s the plan. The curriculum starts at Level 0 with hiragana and katakana, before moving into N5 vocabulary, kanji, and grammar. Later stages are planned to extend through N1.

Will I be able to learn offline?

Offline-first learning is a core design goal. The plan is for downloaded lessons, reviews, and practice tests to work without an internet connection, with progress syncing when you reconnect. This is not yet a released feature.

Which languages and devices are planned?

NihonPath is being designed for Android and iOS, with an interface and grammar explanations in both English and Bahasa Indonesia. A browser-based learning app is not part of the initial roadmap.

Will NihonPath be free?

The roadmap proposes free Kana and N5 content, with premium content for higher levels through in-app purchases. Final pricing and availability have not been announced.
